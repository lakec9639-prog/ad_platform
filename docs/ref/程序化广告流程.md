# 程序化广告核心逻辑全景梳理

---

## 一、交易模式与账户层级

### 1. 常见交易模式

| 模式 | 全称 | 说明 |
|------|------|------|
| **RTB** | Real-Time Bidding，实时竞价 | 目前最主流的模式。每一个用户都有单独的出价，实现"千人千面"的广告展示与实时竞价。 |
| **PD** | Programmatic Direct，程序化直接购买 | 类似于买断包量，与媒体谈定固定价格并结算，但不保证具体量级。 |
| **PDB** | Programmatic Direct Buying，程序化保量购买 | 在 PD 的基础上，额外保证投放量级。 |

### 2. DSP 广告账户层级

```
账户 (Account)
  └─ 代表广告主公司主体，是投放的最高层级
     └─ 计划 (Campaign)
        └─ 核心配置层，包含投放目标（如转化、曝光）以及人群定向策略
           └─ 单元/创意组 (Ad Group)
              └─ 包含出价策略、广告版位选择以及具体的广告素材（图片、文案、视频等）
```

## 二、核心投放逻辑

### 1. 人群挑选与出价依据

- **基础属性**：地理位置、年龄、设备类型等。
- **兴趣标签**：基于用户长期行为打上的兴趣分类。
- **行为信号**：App 内容浏览记录、历史交互行为。
- **上下文 (Context)**：用户当前刚浏览的内容，或预测其接下来可能浏览的内容。
- **Lookalike (相似人群扩展)**：基于现有目标人群（如100万种子用户）泛化，寻找相似特征人群以拓宽投放范围（如扩展至1000万）。
- **Retargeting (重定向)**：针对已投放过或产生过交互的用户进行二次触达。

### 2. 计费方式

#### 媒体侧常见计费

| 计费方式 | 说明 |
|----------|------|
| CPM | 按千次曝光计费 |
| CPC | 按单次点击计费 |
| CPA | 按转化付费（如一个转化出价1元） |
| CPS | 按销售分成（如广告主赚10元，分给媒体5元） |

#### DSP 平台侧计费

多采用转化出价（如 OCPM、OCPX，各平台叫法不同）。

**核心逻辑**：广告主以 CPA 或 CPS 出价，算法平台通过预估转化率，将其自动转化为 CPM 出价，在媒体侧参与竞价。

### 3. 常见广告位

| 广告位类型 | 说明 |
|------------|------|
| 开屏广告 | 打开 App 即见，曝光量大 |
| 信息流/原生广告 | 融入 App 内容（如浏览器资讯），用户体验自然，不易察觉是广告 |
| 视频广告 | 长视频贴片、短视频流广告（如爱奇艺、优酷、腾讯视频） |
| 激励视频 | 用户主动观看广告以获取激励内容，转化行为明确 |
| 搜索广告 | 基于搜索关键词触发的广告位（如百度搜索词后） |

## 三、素材与数据指标

### 1. 素材要求

**核心组成**：图片/视频、文案、标题、按钮、落地页、检测链接。

**适配原则**：需针对不同版位单独制作素材（如开屏、信息流需分别适配尺寸，如 720×1280 竖版），不能一套通用。

**AI 辅助**：部分 DSP 平台支持 AI 生成素材，自动变换尺寸、补齐缺失要素，提升生产效率。

### 2. 曝光到转化漏斗及核心指标

**转化链路**：

```
用户 → 媒体请求 → 曝光（产生扣费） → 点击 → 落地页 → 转化订单 → 下单购买（产生收入/GMV/回收）
```

**核心指标**：

| 指标 | 全称 | 计算公式 |
|------|------|----------|
| CTR | 点击率 | 点击 / 曝光 |
| CVR | 转化率 | 转化 / 点击 |
| CPM | 千次曝光单价 | 曝光成本 × 1000 / 曝光量 |
| CPC | 单次点击单价 | 消耗 / 点击量 |
| CPA | 单次转化价格 | 消耗 / 转化数 |
| ROAS | 投资回报率 | 收入 / 广告消耗 |

### 3. 归因模型

解决多广告触达下的收益分配问题：

| 归因模型 | 说明 |
|----------|------|
| 首次触达 | 归因于用户第一次点击的广告/媒体 |
| 末次触达 | 归因于归因周期内最后一次点击的广告/媒体 |
| 线性归因 | 多次点击平均分配收益 |
| 数据驱动 | 根据用户在 App 内的不同行为权重（如停留时长、加购、下单）进行动态归因 |

> **注**：实际归因中还需考虑跨设备、跨渠道、归因窗口期、数据回传延迟等复杂因素。

## 四、程序化广告项目流程

```
需求确认 → 搭建准备 → 合规审核 → 正式投放 → 数据优化 → 结果汇报
```

| 阶段 | 说明 |
|------|------|
| **需求确认** | 广告主提出投放需求与核心目标 |
| **搭建准备** | 账户准备、计划搭建、素材上传 |
| **合规审核** | DSP 平台审核素材、落地页及调取链接（检查违规内容） |
| **正式投放** | 开启流量竞价与展示 |
| **数据优化** | 回收数据，根据指标调整出价、定向与素材 |
| **结果汇报** | 向广告主同步投放效果与复盘 |
