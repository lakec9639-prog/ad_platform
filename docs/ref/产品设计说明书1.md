# LUMI 烟酰胺精华液7月投放增长系统 — 产品设计说明书

## 1. 项目背景与目标

- **项目名称**：LUMI 烟酰胺精华液7月新品上市投放项目
- **核心目标**：在80万预算内，最大化"首购订单数"与"首购GMV"，实现高效拉新。
- **关键挑战**：
  - 历史数据（4-6月）显示部分渠道（如腾讯广告）CPA波动较大。
  - 需要利用AI实现从"人工盯盘"到"智能决策"的转型。
- **交付物**：自动化投放策略包 + 自动化执行系统原型。

## 2. 数据洞察与策略制定

基于对《客户历史数据_v3.xlsx》的深度分析，我们制定了以下6条核心投放策略。

### 数据洞察摘要

- **渠道表现**：巨量引擎（字节）在"首购订单数"上表现最稳，B站（Bilibili）曝光量大但转化略低，小红书（RED）在"成分党"人群中CTR极高。
- **素材表现**：视频素材（特别是KOL测评、成分解析）的CTR普遍高于0.025%，优于静态图。
- **人群机会**：历史数据中"成分党"和"美妆兴趣"人群转化率最高。

### 6条具体投放策略

## 3. 系统架构设计

为了满足"自动化系统"的要求，我们将构建一个闭环的智能投放中台。

### 系统逻辑图（文字版）

- **输入层**：LUMI素材库 + 人群包标签 + 80万预算配置。
- **决策层（AI大脑）**：
  - **预算分配器**：根据历史ROI，初始分配预算（巨量40%，小红书30%，B站15%，腾讯10%，百度5%）。
  - **实时监控器**：每1小时抓取一次API数据（消耗、转化、CPA）。
- **执行层（自动化规则）**：
  - **启停规则**：若计划消耗 > 200元 且 转化数 = 0 → 自动关停。
  - **调价规则**：若 CPA < 目标CPA * 80% 且 预算剩余充足 → 自动提价20%扩量。
  - **素材轮替**：若某素材CTR连续3小时低于1% → 自动替换备用素材。

## 4. 关键功能模块详解

### 模块一：智能预算分配器

- **逻辑**：基于历史数据计算各渠道的"单位转化成本"。
- **实现**：
  - 巨量引擎历史CPA约为120元，分配权重最高。
  - 腾讯广告历史CPA波动大（有时高达300元），设置"止损线"，一旦超标立即切断预算。

### 模块二：动态创意优化

- **逻辑**：不同渠道用户偏好不同。
- **实现**：
  - 小红书：自动上传竖版视频（9:16），标题带"#美白 #烟酰胺"标签。
  - B站：自动上传横版视频（16:9），前5秒必须有强视觉冲击（使用素材C001）。

### 模块三：归因与反作弊

- **逻辑**：利用《归因数据》中的逻辑，区分"首触"与"末触"。
- **实现**：
  - 对于B站、小红书等"首触"渠道，考核指标放宽（看重点击和加购）。
  - 对于搜索、重定向等"末触"渠道，严格考核ROI（看重成交）。
